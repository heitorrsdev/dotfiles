# dotfiles

Personal development environment configuration files.

This repository contains versioned settings and tooling configuration used across my development environments, making it easier to reproduce and maintain a consistent setup on new machines.

It may include configuration for tools such as:

- Git
- Zsh
- Powershell
- VS Code
- setup and bootstrap scripts

Environment-specific or sensitive information, such as credentials, tokens, private keys, and internal configuration, is intentionally kept out of this repository.

## Structure

```text
dotfiles/
├── git/
├── zsh/
├── pwsh/
├── vscode/
└── scripts/
```

The structure may evolve as new tools and configurations are added.
